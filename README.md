# 1CCPG - Pensamento Computacional em Python

## Descricao
Este repositorio tem como objetivo armazenar todos os codigos, exercicios e conteudos praticos desenvolvidos durante a disciplina de Pensamento Computacional, ministrada no 1 ano do Bacharelado em Ciencia da Computacao da FIAP (Turma 1CCPG - 2026). 

O foco principal deste material e o desenvolvimento da logica de programacao, resolucao de problemas complexos e a construcao de uma base solida na linguagem Python, cobrindo desde os fundamentos ate a implementacao de algoritmos mais estruturados.

## Tecnologias Utilizadas
- Python 3.x

## Estrutura do Repositorio
O repositorio esta organizado cronologicamente e por topicos de aprendizado, refletindo o progresso das aulas ao longo do ano letivo:

- /Fundamentos: Variaveis, tipos de dados, operadores matematicos e logicos.
- /Estruturas_de_Decisao: Condicionais (if, elif, else).
- /Estruturas_de_Repeticao: Lacos (for, while) e iteracoes.
- /Colecoes: Listas, tuplas, dicionarios e manipulacao de dados estruturados.
- /Funcoes: Modularizacao de codigo e escopo de variaveis.
- /Manipulacao_de_Arquivos: Leitura e escrita de arquivos (TXT, CSV).

*Nota: A estrutura de pastas pode variar conforme o avanco da disciplina.*
